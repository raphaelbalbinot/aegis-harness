# 🌐 Regras Modulares — Frontend & Qualidade Web

Carregue este módulo sempre que tocar em HTML, CSS, DOM, React/Next/Vue ou JS client-side.

1. **Modern Web Guidance:** consulte padrões modernos da web (`modern-web-guidance`) evitando APIs obsoletas e garantindo zero achados em varreduras de legado.
2. **Qualidade Web Integral:** combine `accessibility`, `core-web-vitals`, `performance`, `seo` e `web-quality-audit` conforme o escopo da mudança.
3. **Paridade E2E:** fluxos críticos de UI devem manter paridade entre suítes E2E automatizadas e validação em navegador real (`browser-testing-with-devtools`).
4. **Uso Sob Demanda da `/hallmark`:** acione `/hallmark` apenas sob pedido explícito do usuário para páginas *greenfield* ou redesign.
